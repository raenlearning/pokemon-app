# pokemon_app

A new Flutter project.
=======
🐙 Pokemon App (Pokedex)
A modern, responsive Pokedex application built with Flutter. This project demonstrates the implementation of clean architecture, local caching, and reactive state management to browse and manage your favorite Pokémon.

🚀 Features
Dynamic Pokedex: Browse a list of Pokémon with high-quality images using cached_network_image.

Offline Support: Local data persistence powered by Isar Database.

Responsive UI: Optimized for various screen sizes using responsive_framework.

Smooth Animations: Engaging user experience with Lottie animations.

Custom Theming: Retro-style aesthetics using the PressStart2P font and Google Fonts.

Advanced Navigation: Declarative routing managed by go_router.

🛠 Tech Stack
State Management: flutter_bloc (Cubit/Bloc)

Networking: dio for robust API requests.

Dependency Injection: get_it & injectable (Auto-generated DI).

Database: Isar (High-performance NoSQL).

Boilerplate Generator: build_runner for generating code (Isar & Injectable).

Linting: flutter_lints for maintaining clean code standards.

📂 Project Assets
This app uses custom assets to enhance the visuals:

Lottie: Interactive animations in assets/lottie/.

Fonts: Retro PressStart2P typography.

Launcher Icons: Custom icons configured via flutter_launcher_icons.

⚙️ Getting Started
Prerequisites
Flutter SDK: ^3.7.2

Dart SDK
# Clone repo
git clone https://github.com/raenlearning/pokemon_app.git

# Go to folder
cd pokemon_app

# Get packages
flutter pub get

# Generate file (since you're using build_runner)
dart run build_runner build
